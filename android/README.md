# LoadLink Pakistan — Android Main App

Native Android application foundation for LoadLink Pakistan.

- Package: `pk.loadlink.pakistan`
- Language: Kotlin
- UI: Jetpack Compose
- Backend: existing LoadLink Pakistan API
- API base URL: `https://loadlink-pakistan.onrender.com/api/`

The Android app is isolated under `/android` so the existing website and backend files are not changed.

Next step: connect Retrofit/OkHttp to the existing authentication API and implement Login/Signup.
